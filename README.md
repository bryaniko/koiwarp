# Simple Web Application MVP
This project implements a simple full-stack task board web app with a static frontend and Express API backend.
## Features
- Create, list, update, and delete tasks
- Search and filter by completion status
- Basic validation and error handling
- Health endpoint for service checks
- Automated tests for API and frontend utilities
## Run Locally
1. Install dependencies:
   - `npm install`
2. Start the app:
   - `npm start`
3. Open:
   - `http://localhost:3000`
## Quality Checks
- Lint/syntax check: `npm run lint`
- Tests: `npm test`
